## 1. 位序、语义域与快照

### 1.1 RTLIL 位序

Yosys 端口 bit 0 是最低位。RTLIL 拼接 `{x, y, z}` 由右向左映射到低位；例如 `{sr[4],sr[5],sr[6]}` 表示 bit 0/1/2 分别为 `sr[6]/sr[5]/sr[4]`。本文全部映射均以端口位号为准。

### 1.2 原始快照与实验输入

| cell | `before_pmux.il` 原始 B | `after_pmux.il` 实验输入 B | 其它端口 |
|---|---|---|---|
| `$procmux$10` | B[0]=sr[2], B[1]=sr[1], B[2]=sr[0] | `3'b111` | A/S/Y 不变 |
| `$procmux$18` | B0=sr[3], B1=1 | `2'b11` | A/S/Y 不变 |
| `$procmux$27` | B[0]=1, B[1]=sr[6], B[2]=sr[5], B[3]=sr[4] | `4'b1111` | A/S/Y 不变 |

原始连接说明证明来源；五个实验的预期结构以 `after_pmux.il` 为统一输入，不能由实现者自行选择是否先运行 R1′。

### 1.3 语义域

本文“对所有输入”精确指所有二值模块输入和状态位取值。若要求严格保持 RTLIL 四值语义，还必须证明相关 S/A/B 在观察点不为 x/z，或另给四值等价证明，否则拒绝。

`sr` 没有复位，形式环境可能观察到未知初值。S 为 x/z 时删除选择逻辑可能把 x 输出细化为确定值；不能把二值证明默认为四值证明。

## 2. V2-A：旁路 `$procmux$10`

### 2.1 原 cell 的 A/B/S/Y

`$procmux$10` 是 `WIDTH=3` 的 `$mux`：

| bit | A | 原始 B | 实验输入 B | Y |
|---:|---|---|---|---|
| 0 | `sr[6]` | `sr[2]` | 1 | `$procmux$10_Y[0]` |
| 1 | `sr[5]` | `sr[1]` | 1 | `$procmux$10_Y[1]` |
| 2 | `sr[4]` | `sr[0]` | 1 | `$procmux$10_Y[2]` |

- S = `$procmux$11_CMP`。
- `$procmux$11_CMP` 由 `$procmux$20_CMP0` 驱动，比较 `sr == 8'hff`。
- `$mux` 语义为 `Y = S ? B : A`。

### 2.2 为什么所有二值输入都有 Y=A

1. S=0 时，由 mux 定义 Y=A。
2. S=1 时，`sr=8'hff`，所以 A=`sr[6:4]=3'b111`；原始 B=`sr[2:0]=3'b111`，R1′后的 B 也为 `3'b111`。因此 Y=B=A。

二值 S 只有 0/1，两种情况均得到 Y=A。

### 2.3 保留和删除

删除 cell `$procmux$10`，并精确重连：

| 原 Y 位 | 新驱动 |
|---:|---|
| Y[0] | `sr[6]` |
| Y[1] | `sr[5]` |
| Y[2] | `sr[4]` |

等价向量连接为 `connect $procmux$10_Y { \sr [4] \sr [5] \sr [6] }`。必须先重连所有 Y 使用者再删 cell。Y wire 可暂时保留为 alias；只有确认无属性、外部可见性和剩余使用者后，才允许标准清理删除。`sr` 及其 DFF 驱动必须保留。

### 2.4 不能删除的比较器

不得删除 `$procmux$20_CMP0` 或 `$procmux$11_CMP`。A 后 `$procmux$11_CMP` 仍至少扇出到：

1. `$procmux$18.S[0]`；
2. `$auto$simple.cc:194:make_patterns_logic$47.A[0]`，参与 gpioout 写使能。

即使 A+B 同时去掉 `$procmux$18.S[0]`，写使能扇出仍在。

## 3. V2-B：删除 `$procmux$18.B0`

### 3.1 原 PMUX 连接

`$procmux$18` 为 `WIDTH=1, S_WIDTH=2`：

| 项 | 原始连接 | 实验输入 |
|---|---|---|
| A | `sr[0]` | `sr[0]` |
| B0 = B[0] | `sr[3]` | 1 |
| B1 = B[1] | 1 | 1 |
| S0 = S[0] | `$procmux$11_CMP = (sr==8'hff)` | 同左 |
| S1 = S[1] | `$procmux$12_CMP = (sr==8'haa)` | 同左 |
| Y | `$procmux$18_Y` | 同左 |

原文本 `S {CMP_aa CMP_ff}`、`B {1'b1 sr[3]}` 的右端是 bit 0，所以不能把 B0/B1 或 S0/S1 颠倒。

### 3.2 PMUX 的选择和重叠语义

| S1 S0 | 输出 |
|---|---|
| 00 | A |
| 01 | B0 |
| 10 | B1 |
| 11 | 未定义/x |

原生 `$pmux` 是 one-hot 选择器，多选为未定义。某些 `pmux2mux` 降低代码从低位向高位迭代，看起来像 S1 优先，但变换不得依赖该实现顺序。只有证明 S0/S1 互斥后，优先次序才无关。

### 3.3 `S0 -> B0=A`

S0=1 意味着 `sr=8'hff`，于是 `B0=sr[3]=1` 且 `A=sr[0]=1`，所以 `S0 -> B0=A`。在实验输入中 B0 已为常量 1，同一证明为 `S0 -> A=1 -> B0=A`。

### 3.4 S0 与 S1 互斥

S0 要求 `sr=8'hff`，S1 要求 `sr=8'haa`。两个 8 位常量不同，bit 0 已分别要求 1 和 0，因此不存在二值 sr 同时满足：

`(sr==8'hff) & (sr==8'haa) = 0`。

不能用 `full_case` 属性代替证明。必须核对两个 `$eq` 的 A 均为同一个规范化 `sr[7:0]`，宽度为 8、符号参数一致、B 常量分别为 ff/aa。

### 3.5 转换为单分支 MUX

删除 B0/S0，保留 B1/S1；将原 cell 精确变为 `WIDTH=1` 的 `$mux`：

| 新端口 | 映射 |
|---|---|
| A | 原 A = `sr[0]` |
| B | 原 B1 = 1 |
| S | 原 S1 = `$procmux$12_CMP` |
| Y | 原 Y = `$procmux$18_Y` |

可以复用 cell 名 `$procmux$18`，但类型由 `$pmux` 变为 `$mux`，必须删除 `S_WIDTH`，B/S 宽度从 2 降为 1；`WIDTH=1`、Y wire、属性和来源位置保持。

### 3.6 拒绝条件

任一条件成立即零变换：

1. 无法证明 `S0&S1=0`，或试图依赖重叠时的所谓 S1 优先；
2. 无法证明完整的 `S0 -> B0=A`；
3. S0/S1/A/B0/B1 可能为 x/z，且没有二值实验契约或四值证明；
4. cell 类型、WIDTH、S_WIDTH、B/S 物理位、Y 或属性与快照不一致；
5. 比较器宽度、符号、A 信号或常量不匹配；
6. 删除分支会修改共享信号驱动或其它使用位置。

`$procmux$20_CMP0/$procmux$11_CMP` 在 B 单独运行时还供 `$procmux$10` 使用，在所有变体中还供写使能逻辑使用，一律保留。

## 4. V2-C：部分旁路 `$procmux$27`

### 4.1 原 4 位 MUX

S = `$procmux$19_CMP = (sr==8'hfe)`，Y = `$procmux$27_Y`：

| bit | A | 原始 B | 实验输入 B | Y |
|---:|---|---|---|---|
| 0 | `sr[3]` | 1 | 1 | Y[0] |
| 1 | `sr[2]` | `sr[6]` | 1 | Y[1] |
| 2 | `sr[1]` | `sr[5]` | 1 | Y[2] |
| 3 | `sr[0]` | `sr[4]` | 1 | Y[3] |

### 4.2 Y bits 0..2 旁路、bit 3 保留

S=0 时 Y=A。S=1 时 `sr=8'hfe=8'b11111110`：

- bit 0：A[0]=sr[3]=1，B[0]=1；
- bit 1：A[1]=sr[2]=1，原始 B[1]=sr[6]=1；
- bit 2：A[2]=sr[1]=1，原始 B[2]=sr[5]=1。

所以 Y[0..2] 对所有二值输入恒等于 A[0..2]。bit 3 不能旁路：S=1 时 A[3]=sr[0]=0、原始 B[3]=sr[4]=1，选择确实改变输出。

### 4.3 缩成 1 位 MUX 的准确端口

三个旁路位：

| 原 Y 位 | 新驱动 |
|---:|---|
| `$procmux$27_Y[0]` | `sr[3]` = 原 A[0] |
| `$procmux$27_Y[1]` | `sr[2]` = 原 A[1] |
| `$procmux$27_Y[2]` | `sr[1]` = 原 A[2] |

保留 bit 3 的 `WIDTH=1` mux：

| 新端口 | 五变体实验输入 | 若直接从 `before_pmux.il` 构造 |
|---|---|---|
| A[0] | 原 A[3] = `sr[0]` | 同左 |
| B[0] | R1′后的原 B[3] = 1 | 原 B[3] = `sr[4]` |
| S[0] | `$procmux$19_CMP` | 同左 |
| Y[0] | 原 `$procmux$27_Y[3]` | 同左 |

五个正式变体必须使用中间列，即 B=1。可复用 cell 名 `$procmux$27`，但 WIDTH 从 4 变为 1，A/B/Y 只能包含上表的单个位。禁止把整个 Y[3:0] 接到 1 位 Y，禁止颠倒原 Y[0] 与 Y[3]。

`$procmux$19_CMP` 不得删除；它还扇出到：

1. `$auto$simple.cc:194:make_patterns_logic$57.A`；
2. `$auto$simple.cc:194:make_patterns_logic$52.A[1]`；
3. `$auto$ff.cc:337:slice$62.SRST`。

## 5. 五个实验变体的预期结构和前提

共同前提：输入为同一份已验收 `after_pmux.il`；快照完全匹配；采用明确的二值语义或有四值安全证明；无多驱动；位序按本文；只修改列出的三个 cell/Y alias；结构检查和 EQY 必须通过。

| 变体 | 预期结构 | 变体正确性前提 | 必须保留 |
|---|---|---|---|
| 1. A | 删除 10；10_Y[0:2] 旁路到 sr[6],sr[5],sr[4]；18/27 不变 | `S_ff -> A10=B10` 整宽成立 | 三个 eq、写使能、DFF |
| 2. B | 18 从两分支 pmux 变为 `mux(A=sr0,B=1,S=CMP_aa,Y=原Y)`；10/27 不变 | `S_ff -> B0=A` 且 `S_ff&S_aa=0`；满足 x/z 策略 | CMP_ff 全部其它扇出 |
| 3. C | 27 变为只驱动原 Y[3] 的 1 位 mux；原 Y[0:2] 由 sr[3],sr[2],sr[1] 驱动；10/18 不变 | 对 k=0..2，`S_fe -> A[k]=B[k]`；bit3 保持原选择 | CMP_fe、写使能、SRST |
| 4. A+B | 同时满足 A/B；剩余相关选择 cell 为 18 的 1 位 mux 和原 27 的 4 位 mux | A 与 B 前提的并集 | CMP_ff 仍进入 `make_patterns_logic$47` |
| 5. A+B+C | 10 删除；18 为 1 位 mux；27 为只驱动原 Y[3] 的 1 位 mux，Y[0:2] 旁路 | A/B/C 全部前提；同快照原子预检查 | 三个比较器、写使能、SRST、DFF、模块端口 |

组合变体不得按顺序修改后重新分析。A/B/C 必须从同一只读快照生成互不冲突的结构计划，统一预检查后一次提交；不能让标准清理结果充当后续变换的证明。

## 6. B 实现前必须检查的快照字段

B 若另行获得实现授权，至少统一预检查：

1. module 稳定 ID `\test3`、cell 稳定 ID、cell 仍属于 module；
2. cell 类型：10/27 为 `$mux`、18 为 `$pmux`；
3. 参数：10 WIDTH=3，18 WIDTH=1/S_WIDTH=2，27 WIDTH=4；
4. A/B/S/Y 完整 `SigSpec`、端口宽度、每个物理位及 SigMap 后规范位；
5. R1′输入结果：10.B=`3'b111`、18.B=`2'b11`、27.B=`4'b1111`；
6. 18 的 B0/B1、S0/S1 分支编号和物理偏移；
7. 三个来源 eq 的 cell ID、A/B/Y、宽度、SIGNED 参数和 ff/aa/fe 常量；
8. 目标 Y wire 的完整驱动和使用者集合，确保重连后无多驱动、无遗漏；

## 7. C 验收应观察的结构变化

C 应在标准清理前保存精确结构快照；清理后允许无用 alias wire 消失。

1. A：10 cell 消失；原 Y[0:2] 驱动依次为 sr[6],sr[5],sr[4]；`$procmux$20_CMP0` 仍存在。
2. B：18 不再是 pmux，不再有 S_WIDTH=2 或 2 位 B/S；新 mux 精确为 A=sr[0]、B=1、S=CMP_aa、Y=原 Y；CMP_ff 仍存在。
3. C：不存在 4 位 27；保留的 1 位 mux 只驱动原 Y[3]，A=sr[0]、B=1、S=CMP_fe；原 Y[0:2] 依次由 sr[3],sr[2],sr[1] 驱动。
4. A+B：同时满足 1/2，CMP_ff 的写使能扇出仍在。
5. A+B+C：同时满足 1/2/3；最终只剩两个相关的 1 位 mux，三个比较器均仍存在。
6. 所有变体：新增时序 cell=0；DFF/SDFFCE、模块端口、时钟、复位、IO、比较器常量和写使能逻辑不变；无多驱动；Yosys `check` 通过。
7. 所有变体：EQY PASS，并分别记录结构 cell/位宽和 ABC9 后 LUT/DFF/IO。LUT 不下降必须如实记录，不能修改测试期望或判据。
