## 2. 两人环境检查

A、B 必须分别在 WSL Linux 文件系统的独立 clone/worktree 工作，不在 `/mnt/c`、`/mnt/d` 或 `/mnt/e` 长期编译。两人分别记录：

```bash
git remote -v
git branch --show-current
git rev-parse HEAD
git status --short
git submodule status --recursive
git merge-base --is-ancestor 9f75ca1f9834a39a863915b5dae0c7b1e33533bc HEAD
```

工作树必须干净，origin 必须指向中央私有仓库。GitHub 认证只使用浏览器/GCM/PAT，不使用账户密码。

以下全部为真才算完成人员切换：

- A、B 都能访问中央私有仓库；
- 两人环境、输入哈希、工具提交一致；
- 两人工作树和分支相互隔离；
- 两人完成五项书面确认；
- B 的候选已推送且完整提交可达；
- A 明确接受独立审计和最终验收职责；
- B 明确接受全部生产实现和集成修复职责；
- 不再把原 C 的参与作为新提交的必要条件；
- 不因人数减少而允许自审自批。
